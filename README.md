# SchemaCAD

Schema-Editor als Browser-App (Stromlaufschema, Disposition, PV-Strangplan). Eine HTML-Datei, läuft auch offline.

- Online: GitHub Pages (Adresse in den Repo-Einstellungen)
- Bauen: `npm install && node build.mjs` → `dist/schemacad.html`
- Online-Ablage für Datenblätter und Symbol-Bibliotheken: Supabase (`src/cloud.js`), freiwillig, mit Anmeldung. Projekte bleiben Dateien.
